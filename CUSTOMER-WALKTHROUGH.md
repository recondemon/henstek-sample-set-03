# Stillwater walkthrough

## Web atlas — SW-03 / Web

1. Open the web demo. Choose Alder Grove on the illustrated map.
2. Read its observation prompt and choose **Write something down**.
3. Add a title and note, then save. Reload to confirm the local copy remains.
4. Open **My journal**, search for a word from your note and mark it as a favorite.
5. Export the journal. It contains readable JSON; keep the file if you want a backup.

## Pocket journal — SW-03 / Mobile

1. Run the native iPhone target using the platform guide.
2. Add an observation from Outside. Choose a place and kind, then save.
3. Open Journal to search or filter favorites. Tap an entry to edit it.
4. In Places, choose **Write here** to start a note with that place selected.
5. Use Journal’s backup menu to export or import a compatible journal.

## Writing workspace — SW-03 / Desktop

1. Open the browser preview or run the Electron app.
2. Choose a place in the left column, then an observation in the middle column.
3. Edit it in the right workspace. Keep it close to add it to Favorites.
4. Import the JSON export from the web sample, review the replacement prompt and confirm. Your added web note should now appear.
5. Export your desktop journal before making further changes.

The samples use separate local storage. Import/export is a deliberate manual transfer, not live synchronization. All initial places and observations are fictional. Use only sample content when trying them.

## Commissioning a variation

You can request a reading diary, travel scrapbook, craft journal or another personal tool. Reference the platform and style independently: “SW-03 / Desktop writing with SA-02 / Web type and colors.” Accounts, shared notebooks, uploads, real maps, encryption and store distribution are separate scope decisions.

## Try every platform in the gallery

Click a sample screen or **Try interactive preview** to open the working demo without leaving the gallery. Web and desktop use their existing browser interfaces; `/mobile/` is a browser adaptation of the SwiftUI screens. It is not an iOS emulator and does not include native device or file integrations. Mobile edits live in memory until reload or Reset demo. The viewer keeps the reference label and inquiry link visible. Press Escape or Close to return; Open separately is available if browser embedding/storage is restricted.
